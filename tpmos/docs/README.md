# docs — Dokumentacja

Dokumentacja TPMOS: architektura systemu, decyzje projektowe (ADR), diagramy,
przewodniki wdrożeniowe i operacyjne (runbooki).

Sugerowana zawartość:
- `architecture.md` — ogólny opis architektury i przepływów.
- `adr/` — Architecture Decision Records.
- `runbooks/` — instrukcje operacyjne (deploy, awarie, backup).
