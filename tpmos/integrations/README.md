# integrations — Integracje zewnętrzne

Łączniki do usług zewnętrznych wykorzystywanych przez szkołę:
- Komunikacja: WhatsApp, e-mail, formularze.
- Social media: Instagram, Facebook, TikTok, YouTube.
- Inne: kalendarz, płatności, arkusze.

Każda integracja w osobnym podkatalogu, z opisem konfiguracji i sekretów
(sekrety wyłącznie przez zmienne środowiskowe — nigdy w repo).
